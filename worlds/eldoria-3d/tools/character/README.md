# Character pipeline (eldoria-human.glb)

`build.sh <makehuman/data> <python-with-bpy> <dir-with-node_modules/gltfpack>` rebuilds `assets/models/eldoria-human.glb`;
`node tools/gen_builtin_models.mjs` then embeds it in `src/builtin-models.tsx` so the world JSON is self-contained.

## What the GLB contains
- `body_skin`: one mesh, 12 primitives (head, neck, chest, spine, hips, upperarm, forearm, hand, thigh, shin, shinlow, foot), so an
  outfit hides exactly the skin it covers (`outfit_*` node extras `hide`).
- Morph targets: `female`, `build_slender|lean|sturdy|broad`, `eyeBlinkLeft/Right`, `jawOpen`, `browDownLeft/Right`, `mouthSmileLeft`, `wince`, `ears_pointed`.
- Skeleton: the game's 15 joints + `lfoot`/`rfoot`; `socket_hand_r|hand_l|shield|head|back` empties reproduce the procedural frames.
- Variants: `outfit_light|medium|heavy|robe|bare`, `hair_short_crop|messy_layered|long_straight|ponytail|braided|topknot`, `beard_full`.
- Materials named `<kind> @main|@cloth|@trim|@none`: the runtime multiplies the calling palette colour onto the greyscale albedo.
- 23 clips with the gameplay names and exact durations (`retime:false`, `bakedFades:true` in `EldoriaMeta` extras).

## Known limits
- One base face (MakeHuman's average young adult); face variety comes only from the female/build/ear morphs and skin/hair tint.
- Hair is card-based and rigid with the head; clothing is a skin-tight layer plus the MakeHuman skirt shell (no cloth simulation).
- No LOD meshes yet; the Settings → Characters → Classic option uses the light procedural bodies.
